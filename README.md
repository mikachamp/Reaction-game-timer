# Reaction Game Timer

A modern, interactive web application designed to test and measure your reaction time. 

Built as a part of the GitHub Vibe Coding course, this project features a sleek, responsive design and provides precise feedback on how quickly you can react to visual cues.

## ✨ Features
- **Accurate Timing:** Measures reaction times in milliseconds.
- **Modern UI:** Features a premium design with smooth gradients, animations, and a polished user interface.
- **Responsive:** Works seamlessly across desktop and mobile devices.
- **Instant Feedback:** View your reaction time immediately after clicking.

## 🚀 How to Run Locally

Since this project is built with standard web technologies, getting it up and running is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/mikachamp/Reaction-game-timer.git
   ```
2. Navigate to the project folder.
3. Open `index.html` directly in any modern web browser.
   - *Alternatively, use a tool like the **Live Server** extension in VS Code for hot-reloading.*

## 🛠️ Tech Stack
- **HTML5:** For the structure of the application.
- **CSS3:** For styling, leveraging modern features like CSS variables, flexbox, and gradients.
- **JavaScript (Vanilla):** For the core game logic and DOM manipulation.
