Benchmarking Details

Precision Metrology

This benchmark measures motor reaction time using Javascript's High Resolution Time API (`performance.now()`). It isolates and records human response lag triggered by visual stimuli on high refresh rate displays.

Performance Target

To prevent graphics calculations from introducing artificial input latency, the 3D scene utilizes optimized geometries, simplified shader calls, and garbage-collected objects. Rendering runs on a dedicated WebGL context.
